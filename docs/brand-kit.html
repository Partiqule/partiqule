Design system · version 1

A brand kit in paper and moss.

Everything in the Partiqule app follows the rules on this page. Cream backgrounds, warm typography, asymmetric shapes, moss and amber accents, and a voice that reads labels for you without talking down.

Foundation

Six things we always do.

These are the principles that precede every design decision. When something feels off, start here and ask which of these got missed.

01
Copy carries more weight than chrome. Every string is a voice moment.
02
The score is never the whole story. It sits next to a conversational verdict, not alone.
03
Your shelf is the spine. Every scan ends on a reminder of the collection the user is building.
04
One decision per moment. Each screen asks the user to do exactly one thing.
05
Honest over comfortable. Warmth comes from voice, not from softening facts.
06
Completion is ceremony. Loading, scanning, and shelving each get their own moment.
Color

Cream on cream, with moss and a touch of amber.

The palette is warm, earthy, and low in saturation. Score colors are natural earth versions of green, yellow, and red. Nothing in the system is fire-engine or neon.

Typography

Two fonts, each with a job.

Fraunces does the warmth. DM Sans does everything else. Data bits that used to be mono are now DM Sans uppercase with letter-spacing, keeping the small-caps feel without the typewriter overtone.

Shapes

Nothing is stamped.

Every tile, card, and circle in the app uses an asymmetric radius so it looks hand cut. Six tile shapes for thumbnails, three card shapes for feed cards and alternatives, and one CTA shape for the largest surfaces. Cycle through them so adjacent tiles never match.

Voice

Write like a friend reads labels.

First and second person. Specific over vague. Short sentences. Real words. The test: would a friend say it out loud? If no, rewrite.

Never

Things we don't do.

These moves signal generic AI SaaS. They're the tells we're trying to escape. If you catch any of them sneaking back in, pull them out.

Outfit as a typeface anywhere
Purple 7c3aed as an accent
Pure white or cold navy surfaces
Icons inside colored squares
Emoji in any UI string
Symmetric hard rounded rectangles
Glow halos around interactive elements
Dashboard voice (Overview, Data, Details)
Pulsing or bouncing animations
System fonts as substitutes
Score bigger than verdict headline
Any screen without a path back to the shelf
Everything else is tuning.
