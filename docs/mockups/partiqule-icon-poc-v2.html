How this actually works

The rough.js library is inlined directly into this HTML file — no CDN call, no loading step. It takes basic shape commands (rectangle, circle, line, path) and renders them with Perlin-noise imperfections.

For production in React: npm install roughjs, then create a RoughIcon component that renders an inline SVG on mount. Lock a seed per icon or per user for stability.

Roughness is currently set to 1.3. Drop to 0.9 if too sketchy. Push to 1.6 if not sketchy enough.
